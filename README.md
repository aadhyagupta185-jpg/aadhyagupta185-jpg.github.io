# Aadhya Gupta — Textile Design Portfolio 2026

A standalone static website adapted from the design direction of the existing Aadhya Gupta portfolio website. Includes six collections from the 39-page updated PDF, responsive collection cards, image viewer, keyboard navigation, and accessible controls.

## Preview

Run `python3 -m http.server 8000` in this folder and visit http://localhost:8000.

## Publish

Copy `index.html` and the complete `assets/` directory to the root of the existing GitHub Pages repository, or deploy these files on any static host. Existing `images_web/` and `thumbs/` assets are not required by the new page. Merge changes only after checking the deployed preview.

The background and images are web-optimized renders of the supplied 39-page portfolio, allowing the new design to stay faithful to original visuals. Pages 38 (letters) and 39 (thank you) are not part of the project viewers, but their assets are included in `/assets`.
